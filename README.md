# Java OOP Interview Prep

A Java source repository for practicing object-oriented programming and interview-oriented concepts. The project keeps its examples under `src`.

## Technology

- Java
- IntelliJ project metadata is present; no build descriptor is currently listed at the repository root.

## Project layout

- `src/` — Java practice sources
- `.idea/`, `oops.iml` — IDE metadata (not required to understand the examples)

## Run

Install a JDK, clone the repository, and open it in a Java IDE. Compile and run individual classes that contain a `main` method. No application server, database, or environment configuration is documented.

```bash
git clone https://github.com/ChakaliKrisna/java-oops-interview-prep.git
```

The repository currently has no build/test instructions or topic index; add links to the relevant source examples as the collection grows.
